How GitHub Works

A simple demo website, hosted on Vercel.

1. Repository

A folder for your project. It stores all your files and their full history.

2. Commit

A saved snapshot of your changes, with a short message describing what changed.

3. Branch

A separate copy of your work where you can try changes without breaking the main version.

4. Pull Request

A request to merge your branch into the main branch, so others can review it first.

5. Deploy

When changes land on main, Vercel automatically rebuilds and updates this website.

Edit this page on GitHub, commit the change, and watch the site update!
